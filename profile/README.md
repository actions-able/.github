# Welcome to Actions-able

An open-source organization focused on **GitHub Actions**, maintained by its members.

---

## Awesome Lists

The curated list [awesome-actions](https://github.com/actions-able/awesome-actions) — originally created by [Sarah Drasner](https://github.com/sdras/awesome-actions) — has been maintained here since March 2025.

> [!NOTE]
> The fork is maintained based on the contributions proposed to the upstream repository, read more on the [associated project](https://github.com/orgs/actions-able/projects/3).

## Actions

Below is the list of GitHub Actions maintained by the organization and its members.

> [!NOTE]
> Actions marked with :alien: are maintained outside **Actions-able** by individual maintainers.

### Data manipulation

| Action | Description |
| --- | --- |
| :alien: [github-slug-action](https://github.com/rlespinasse/github-slug-action) | Expose slug values of GitHub environment variables |
| :alien: [slugify-value](https://github.com/rlespinasse/slugify-value) | Slugify a value |
| :alien: [shortify-git-revision](https://github.com/rlespinasse/shortify-git-revision) | Shorten a git revision |
| :alien: [git-commit-data-action](https://github.com/rlespinasse/git-commit-data-action) | Expose git commit data |

### File manipulation

| Action | Description |
| --- | --- |
| [envsubst-action](https://github.com/actions-able/envsubst-action) | Substitute environment variables in files using `envsubst` |
| :alien: [drawio-export-action](https://github.com/rlespinasse/drawio-export-action) | Export draw.io diagrams |

### Release management

| Action | Description |
| --- | --- |
| :alien: [release-that](https://github.com/rlespinasse/release-that) | Automate releases |
